# Lario – Branding

Der aktuelle Logoentwurf liegt in [lario-logo.png](lario-logo.png). Er zeigt ein Nest mit drei Familienpunkten unter einem schützenden Dachbogen. Dunkelblau und Türkis stehen im Entwurf für einen ruhigen, freundlichen Haushüter.

Der Name Lario verbindet Mario mit Lar, dem römischen Haushüter. Das PNG enthält Symbol und Schriftzug auf hellem Hintergrund. Es ist ein Logoentwurf; eine separate App-Icon-Datei und eine Vektorfassung sind noch zu erstellen.

Der frühere Doppel-M-Entwurf bleibt als historische Referenz unter [archive/moneymap-icon.png](archive/moneymap-icon.png) erhalten. Er ist nicht das aktuelle Logo.
